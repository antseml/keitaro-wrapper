# Frontend

React + TypeScript application. Run `npm install` then `npm run dev` from this directory. Vite forwards `/api` to FastAPI at `127.0.0.1:8000`. Build with `npm run build`.

The interface uses the API contract in `../backend/API_CONTRACT.md`. The browser never receives the Keitaro key.

Design direction: a precise, calm operations console for campaign routing. Its light ink surfaces keep the controls quiet; only the traffic route and unpublished changes receive a stronger mark. The visual signature is the numbered route in the creator and a small status dot in each stream.

Design process adapted from **unslop** by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), licensed under CC BY 4.0.
